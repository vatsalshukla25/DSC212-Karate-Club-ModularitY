# DSC212 – Karate Club Modularity

This assignment focuses on community detection in Zachary's Karate Club graph using recursive spectral modularity.

The implementation uses eigenvalues and eigenvectors to divide the graph into communities, visualize the partitions, and analyze degree centrality, betweenness centrality, closeness centrality and clustering coefficients.

The assignment is implemented in Python using NumPy, NetworkX, Matplotlib and Pandas in a Jupyter Notebook.
